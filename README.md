Finanças Dupla 💰
Aplicativo simples para controle financeiro em dupla, desenvolvido em HTML, CSS e JavaScript.
Permite que duas pessoas registrem entradas e saídas de dinheiro, acompanhem o saldo e organizem suas finanças de forma colaborativa.

🚀 Funcionalidades
Registro de transações: adicionar entradas (receitas) e saídas (despesas).

Cálculo automático: soma dos valores e atualização do saldo em tempo real.

Interface simples: fácil de usar, direto no navegador.

Controle em dupla: pensado para duas pessoas gerenciarem juntos.

📂 Estrutura do Projeto
index.html → Página principal do app.

style.css → Estilos visuais.

script.js → Lógica de funcionamento (cálculo e manipulação de transações).

🛠️ Como usar
Clone este repositório:

bash
git clone https://github.com/taliaalmeida/financas-dupla.git
Abra o arquivo index.html em qualquer navegador.

Comece a registrar suas transações e acompanhe o saldo.

🎯 Objetivo
Facilitar o controle financeiro compartilhado, promovendo transparência e organização entre duas pessoas.
